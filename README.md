# 音准练习 · 听音辨名

听音辨名 / 绝对音感训练小工具。纯 Python 标准库实现，不需要任何音频文件或第三方依赖（装有 numpy 时音色生成更快）。

## 运行

    python3 tone_practice.py

## Web 版（纯静态，托管到 GitHub Pages）

页面在 [docs/index.html](docs/index.html)，完全在浏览器里运行，不需要任何后端：音源由桌面版加法合成的 JS 移植（Web Audio）实时生成，错题集存在浏览器 localStorage。本地预览直接双击打开该文件即可，或：

    python3 -m http.server -d docs

托管：把仓库推到 GitHub 后，在仓库 **Settings → Pages** 选择「main 分支 / (docs) 目录」即可，之后访问 `https://<用户名>.github.io/<仓库名>/`。

## 功能

- 一组练习可设题数（5 / 10 / 20 / 50）：随机播放所选「调性 × 八度」音阶中的音，点击音名按钮直接判定正误；答对答错都自动进入下一题
- 一组结束自动总结：本轮得分、答对哪些音、答错哪些音
- 错题集：答错、跳过或看答案的音自动收录（保存在 `~/.tone_practice_mistakes.json`，按音高合并等音写法）；该音后续作答正确率达到 95% 即移出。错题专项练习只考当前调性音阶里错过的音，选项与日常练习一致（列出整个音阶）
- 「上一题 / 下一题」可回看与跳题（未作答的题跳过计为错误，已答题回看不能重答）；「播放」与「重听」合用一个按钮，随会话状态切换
- 内置钢琴音色：加法合成（泛音 + 不谐和系数 + 指数衰减包络），首次运行在系统临时目录生成 WAV 缓存
- 调性：11 个大调、6 个和声小调、半音阶；八度：1–6 或「随机」
- 音名按钮按当前调性列出全部音，采用调内规范写法（F♯ / B♭）
- 答案附唱名（do re mi …）
- 统计：已答 / 正确 / 准确率 / 连对与最佳连对；最近 12 题对错记录
- 快捷键：空格 = 下一题（无进行中练习时开始一组）
- 重听当前音、看答案（计为错误）、自动下一题（可关）

## 文件

- `tone_practice.py` — 桌面版主程序（界面 + 题目逻辑 + 音源合成与播放）
- `docs/index.html` — Web 版纯静态页面（GitHub Pages 托管，无后端）
- `smoke_check.py` — 自检脚本（`uv run python -m src.smoke_check`，不发声）

## 平台

macOS 用 afplay，Windows 用 winsound，Linux 用 aplay / paplay。
